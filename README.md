# Featured Work

## 🚦 Smart Traffic Management System
**AI-powered multimodal traffic intelligence system**

A real-time traffic monitoring and control platform designed to improve traffic flow and prioritize emergency vehicles.

**Highlights**
- Vehicle and emergency vehicle detection using **YOLO**
- Traffic light state recognition using a secondary vision model
- Emergency siren detection using a **YAMNet-based audio classifier**
- Integrated computer vision and audio intelligence for real-time decision support
- Designed with smart-city and emergency-response scenarios in mind

**Tech:** `Python` `YOLO` `YAMNet` `OpenCV` `Deep Learning`

> 🎓 Graduation Project — Hashemite University

## 🖼️ Musée
**AI-powered interactive museum guide**

An intelligent museum experience that recognizes artwork from images and lets users explore paintings through grounded AI conversations.

**Highlights**
- Artwork recognition with **GPT-4o Vision**
- Identification of title, artist, year, and artistic movement
- **RAG-powered conversational assistant**
- MongoDB-backed artwork knowledge
- Saved galleries, quizzes, and shareable artwork cards
- Full-stack authentication and application architecture

**Tech:** `Node.js` `Express.js` `MongoDB` `GPT-4o Vision` `RAG` `Docker`
